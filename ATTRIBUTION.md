# Source

The pond simulation, fish geometry, and text-tile rasterizer in `src/world.ts`,
`src/shape.ts`, and `src/renderer.ts` are adapted from **Dao Ho's portfolio**:

- https://github.com/Dao-Ho/portfolio
- https://www.daoho.dev/
- Reference commit: `914651c33f254e52bfee9dca5164264c2c33ebfe`
- Original files: `src/app/components/koi-pond/{world,shape,renderer}.ts`

The terminal surface, command-line interface, input handling, and tests were
added for this adaptation. Browser page content, analytics, and dependencies
are not included.

The reference repository did not contain a project license at this commit.
This adaptation retains attribution and does not assign a new license to the
upstream code.
